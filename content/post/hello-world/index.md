## 这是什么？

这是我用 Hugo + Stack 主题搭建的个人博客，托管在 Netify上

## 如何发布新文章？

在 `content/post/` 目录下新建一个文件夹，比如 `content/post/我的新文章/index.md`，然后写 Markdown 内容即可。

```bash
# 也可以使用命令快速创建草稿
hugo new post/my-new-post/index.md
```

文章写后，推送到 GitHub
